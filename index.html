Watch list

One ID per line with an optional label after it, or label = ID; # starts a comment. Public IDs only, never a seed.

Data source

Uses /v1/tick-info, /v1/balances/{id}, /v1/assets/{id}/owned and /possessed. Each refresh sends every ID in the list to this server.

SC shares = assets issued by the zero ID (smart contract shares). “Since start” counts from the first load or Reset changes. Changes are found by comparing each refresh with the previous one; an ID that fails to refresh keeps its last data and is never reported as a change. The list, balances and change log stay in this page's memory unless “Remember on this device” is ticked.
